# Reflex Blitz — Reaction Speed Test App

A lightweight reaction-time benchmark web app built with **React 19 + TypeScript + Vite**. Wait for the screen to turn from red to green, click as fast as you can, and get your exact reaction time in milliseconds (ms).

## Tech Stack

- React 19 + TypeScript
- Vite 6
- Lucide React

## Run Locally

**Prerequisites**: Node.js

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Build for production
npm run build
```
