# Reflex Blitz — 反应速度测试应用

基于 **React 19 + TypeScript + Vite** 构建的轻量级反应速度测试 Web 应用：屏幕从红灯状态随机切换为绿灯，用户立即点击后实时计算并展示反应耗时（毫秒 ms）。

## 技术栈

- React 19 + TypeScript
- Vite 6
- Lucide React 图标库

## 本地运行

**环境要求**：Node.js

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 构建生产版本
npm run build
```
